# Agent Note: 基元与设置外壳中的 UnieAI 界面度量

Status: implemented

[English](2026-08-22-unieai-chrome-metrics.md) | 中文

## Problem

本仓库是 DeepSeek Harness 的一个分支，以 UnieAI 产品的形态发布；[品牌替换](2026-08-22-unieai-rebrand.zh.md)只改动了标识与令牌取值。界面因此仍沿用 DeepSeek 的 figma 几何，于是产品负责人会与 UnieAI Copilot 参考实现逐一比对的两处界面并不一致。

账号下拉由 `ui-primitives` 的 `Menu` 按 figma 卡片绘制——宽 218、圆角 12、行高 40、内边距 `8px 10px`、字号 14/22——而参考实现是宽 240、圆角 6、行高 36、内边距 `8px 12px`、字号 14/20。该基元把列表传送到 body，`className` 落在锚点包装元素上，因此任何调用方都够不到这些度量。设置面板则是一张 800x800、圆角 24 的卡片，标题位于 188px 的导航栏内；而参考实现的对话框宽 70vw、高 90vh、圆角 8，标题位于横跨两栏的页眉横带中，两栏在其下方居中。

## Decision

参考实现的下拉度量成为该基元的默认值，而非一个变体。`Menu` 的卡片宽 240、圆角 6，保留 4px 内缩；一行高 36，内边距 `8px 12px`，字号 14/20，圆角 4；标题行取与行相同的 12px 内缩；嵌套卡片以 128px 为下限贴合其行。本产品中的每个菜单都是同一套界面；若保留第二套菜单度量，账号菜单将处于一种视觉语言，另外十处调用点处于另一种——而这正是本次工作要消除的割裂。

既有的两个尺寸选项无需改动即可吸收此变化。`compact`（JsonTree 的复制菜单）重述了卡片宽度、内缩、圆角、行高、间距、内边距、圆角与字体，因此它绘制的一切都不动。`dense`（工作区分组菜单）只覆盖纵轴，在新的 12px 内缩上保持其 34px 行高。

`MenuLabel.text` 现为 `ReactNode`。标题行需承载其持有者绘制在其上的标记，而参考实现的账号页眉是一个标签，内含地址，旁边是作为描边药丸的套餐；只有账号包知道套餐是什么。

设置外壳即参考实现的对话框，由其 Tailwind 源码折算为 CSS Modules。`SettingsRoot` 渲染一条横跨面板整宽的页眉横带——标题、一行摘要，以及注册方持有的操作，其内容收束于 896px 版心——其下由一个滚动区域同时容纳两栏，并按 1024px 版心居中：176px 的导航吸附在滚动区顶端下方 16px 处，间距 32px，分区在其右侧。低于 768px 时两栏堆叠，导航变成一条横向滚动的行带并隐去分组标题；低于 640px 时面板铺满全屏且不带圆角。关闭按钮钉在面板一角而非排布在横带内，因为横带内容按版心居中，而关闭属于对话框本身。

横带上的标题直接充当对话框的可及名称。参考实现把它的 `DialogPrimitive.Title` 标为 `sr-only` 并在可见的 `h1` 中重复同样的文字，是因为 Radix 从该元素取可及名称，而 shadcn 的标题位置放不进横带；本外壳持有自己的对话框元素，因此由可见标题承载 `aria-labelledby`，无需第二份同样的文字。

摘要行与导航的分组标题一样属于外壳文案，因为没有哪个注册方持有关于其他注册方的排列。它只描述面板而不逐一列举分区：存在哪些分区是组合方式的事实，而参考实现自身的列举点名了本构建并不具备的页面。

## Alternatives considered

**为参考度量新增一个有文档的 `Menu` 变体。** 予以否决，因为那恰恰保留了本次要消除的不一致：账号菜单与参考实现一致，而同一产品中其他所有下拉都不一致。取而代之的做法是逐一核查该基元的其他消费方——没有任何调用方按卡片尺寸设定锚点、测量行高或覆盖这些属性，而两个尺寸选项已经重述了各自所需。

**照搬参考实现的通栏菜单分隔线（`-mx-1 my-1`）。** 因存在实际代价而否决：对没有子菜单的菜单而言 `.viewport` 就是滚动盒，一条越出其行内边缘 4px 的细线属于可滚动溢出，于是每个带分隔线的菜单都会长出横向滚动条。分隔线改为占满行列的宽度。

**照参考实现的做法，在可见标题旁再放一个视觉隐藏节点。** 予以否决：该节点的存在是为了满足 Radix，而本外壳并不承担那份归属；在此重复一份可及名称只有代价，没有收益。

## Consequences

十处 `Menu` 调用点随基元一同变化：输入区的权限选择与智能体预设座位、工作区选择器、工作区浏览器及两处行操作菜单、设置「通用」中的各行（权限预案、语言、忙时回车行为）、账号菜单，以及 JsonTree 的复制菜单。每一处都在运行中的应用里打开并测量：所有非 `compact` 列表现为宽 240、圆角 6、行高 36，`dense` 保持 34，`compact` 原样不变。

在 1440 宽度下设置分区多得约 120px 宽度，并摆脱了面板固定的 800px 上限，因为内容栏现在是 1024px 版心减去导航与间距后所余。没有任何分区被改动。

`ui-model-selection` 自行绘制下拉而非消费 `Menu`，因此模型选择器保持圆角 12 与 40px 行高，成为本产品中唯一与其他下拉不一致的下拉。

## Deferred

账号菜单的页眉仍是两行朴素标题——地址与套餐——而参考实现是一个标签，套餐作为描边药丸。基元现已接受节点；药丸标记属于 `ui-unieai-account`，本次变更落地时该包由另一项变更持有。
