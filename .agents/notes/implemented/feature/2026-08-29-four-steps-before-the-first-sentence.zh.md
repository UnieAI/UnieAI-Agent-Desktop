# Agent Note: four steps before the first sentence

Status: implemented

[English](2026-08-29-four-steps-before-the-first-sentence.md) | 中文

## Problem

這個殼預設了「用過類似程式的人」。第一個畫面要你先選一個 workspace。輸入框提供一個「存取模式」，而它的選項是機器名稱（`workspace-write`）。沒有任何地方說過 agent 拿到那個資料夾之後會做什麼，也沒說過它根本可以被指到另一台電腦上。對這個產品現在面向的人來說，那是在寫下第一句話之前的四個陌生決定——而每一個都是一個關掉視窗的地方。

用詞是其中一半，那部分另外修。另一半是：從來沒有人被告知這個程式**做什麼**。

## Decision

**四個步驟、只出現一次、而且從第一格就能離開。** 不是功能清單，而是一個人在第一分鐘裡必須做的四件事，依照他遇到它們的順序：挑一個資料夾、用平常講話的方式問、在它動你的檔案之前先看過，然後才是它可以在別的地方執行。

第四個刻意放在最後。遠端機器是這個產品做得最有意思的事，也是新使用者最不急的事；放前面會讓人對「這是拿來做什麼的」學到錯的一課。

**是場景，不是圖示。** 每一步都是真實介面的小型模擬，加上一個會把動作做一遍的游標。圖示說的是「有這個功能」；這裡要說的是「你該做什麼」，而一個指標移到按鈕上、按鈕跟著反應，是說出「按那個」最短的方式。這個做法來自 copilot-v2 的 `first-run-scenes.tsx`，它得出了同樣的結論——「教學要示範怎麼用，而不是給一個抽象圖示」——只是這裡用這個產品自己的 token 畫，不是那一邊的。

**純 CSS，跑在共用的六秒週期上。** copilot-v2 用 `motion/react`，是因為那個應用本來就帶著它；為了讓八個方框動起來而把一個動畫 runtime 加進這個桌面 bundle，代價由所有從來不會打開導覽的人一起付，而「在這些時間點改變 opacity 與 transform」正是樣式表直接表達得出來的東西。`prefers-reduced-motion` 會把它全部停下，並讓每個場景停在讀得懂的最後一格。

**關閉是元件自己的答案；設定負責的是「不要再回來」。** 寫入是一次可能根本不會落定的往返（偏好只存在記憶體裡的部署），而一個要等儲存同意才關的對話框，看起來就是一個壞掉的控制項。當那個答案還在路上時導覽保持隱藏，因為 `loading` 不等於「沒看過」，而每次啟動都對一個已經關掉它的人再顯示一次，比晚一點顯示更糟。至於根本無法保存偏好的部署，它會顯示，因為全新安裝正是它存在的對象。

## Alternatives considered

**在真實介面上加提示氣泡或指引標記。** 它們指的是真的東西，那是優點，而它們需要介面不要動：每一個都是進到別的套件標記裡的一個選擇器，而那個標記搬家時不會有任何東西失敗。模擬同樣會悄悄過期，但它過期在一個一看就是「一張畫」的檔案裡。

**用影片或 GIF。** 出貨更重、不重錄就無法在地化，而且沒辦法尊重 `prefers-reduced-motion`。

**每次啟動都顯示，直到使用者做了什麼為止。** 它能接觸到那些沒讀就跳過的人，同時也懲罰了每一個第一次就看懂的人。

**什麼都不做，只修用詞。** 用詞的改動是真的、也出貨了，但一個空畫面上的任何措辭都回答不了「這個程式是拿來做什麼的」。

## Consequences

新使用者在被要求做任何決定之前，先被告知這個產品做什麼。代價是一個描述另一個介面的介面：那些模擬是畫出來的，所以輸入框或資料夾選擇器一改，它們描述的就會是一個已經不長那樣的東西，而那件事發生時不會有任何測試變紅。

而且沒有回頭路。一旦關掉，產品裡沒有任何地方會再提供它——想要的人得手動去清那個設定。

## Verification

在跑起來的 `rabi web` 上、用真實瀏覽器端對端驅動過：全新 profile 下導覽會出現、四個步驟都能渲染與前進、完成會關閉，而重新載入之後它保持關閉——設定文件裡寫著 `first-run: seen: true`。

兩條規則有單元測試，而第一條的變異會讓它變紅：位置推導會夾在範圍內而不是讀過頭，以及那個序列就是那四個場景、依那個順序、沒有任何一個場景被用兩次。

namespace 自己的命名規則在那次驗證中抓到一個真的錯誤：`firstRun` 被設定服務拒絕（`must match /^[a-z][a-z0-9-]*$/`），而那個拒絕被註冊的 callback 吞掉了，留下一個每次啟動都重新出現、卻什麼都沒記錄的導覽。它現在叫 `first-run`。
