# @unieai/uad-machines

[English](README.md) | 中文

工作發生在哪裡：這台電腦，或是使用者連得到的某台機器。

## 它是什麼

一個服務回答介面需要的兩個問題——有哪些機器、現在用的是哪一台——而且第二個答案會跨重啟記住。它不持有連線、也不執行指令；那是[路由式執行世界](../execution-router/README.zh.md)的事，而它會來問這個服務該用哪個目標。

清單不是這個套件自己維護的。它是 `local` 加上使用者自己 OpenSSH 設定裡的 alias，每次呼叫都透過 `ctx.ssh` 重讀。第二本機器名冊就是第二個要維持正確的地方，而第一本早就寫好了。

這台電腦永遠排第一、也永遠在。沒有 OpenSSH 設定的部署仍然有地方可以工作，而一個失去所有遠端機器存取權的人，仍然回得來。

## 選一台

`select(id)` 會拒絕沒有人提供的機器，並說明有哪些可選。存下一個未知目標，等於留給使用者一個「每個指令都失敗」的 Rabi，直到他們重新找到那個設定、並想通它是什麼意思為止。

當前目標每次呼叫都從設定重讀，而不做快取：使用者正在換機器的那一刻，正是過期答案最不能出現的時候。

## Model Experience

無。此套件不註冊任何 tool、prompt、schema 或 context：它回答有哪些機器、現在是哪一台，而模型兩者都不會被告知。

#### KV Cache effect

無。這裡不貢獻任何 prompt 片段、工具定義或 context 條目，因此不會移動任何重用邊界。

## 已知限制與未完成項目

- **一次一台機器。** 當前目標是單一持久值，所以行程內每個 session 都在同一台機器上工作。要讓 workspace 各自記住自己的機器（於是兩個對話能同時在兩台機器上工作），需要一個這個服務目前沒有的紀錄欄位。
- **機器出現在清單裡是因為它被設定過，不是因為它有回應。** 列舉時不做可達性探測；`ctx.ssh.probe()` 是存在的，想要即時狀態指示的介面自己對每台機器呼叫它。
