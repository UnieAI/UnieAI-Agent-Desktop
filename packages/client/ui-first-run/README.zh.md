# @unieai/uad-client-ui-first-run

[English](README.md) | 中文

四個步驟，在第一次打開這個程式時出現，之後不再出現。

## 它為什麼存在

這個殼其他每一個地方都預設了「用過類似程式的人」。第一個畫面要你先選一個 workspace；輸入框提供一個存取模式；而沒有任何地方說過，agent 拿到那個資料夾之後會對它做什麼。對這個產品現在面向的人來說，那是在寫下第一句話之前的四個陌生決定。

## 它教什麼，又刻意不教什麼

不是功能清單，而是一個人在第一分鐘裡必須做的四件事，依照他遇到它們的順序：**挑一個資料夾**、**用平常講話的方式問**、**在它動你的檔案之前先看過**，然後才是**它可以在別的地方執行**。

第四個放在最後是刻意的。遠端機器是這個產品做得最有意思的事，也是新使用者最不急的事；把它提前，會讓人對「這是拿來做什麼的」學到錯的一課。

## 是場景，不是圖示

每一步都是一個**真實介面的小型模擬，加上一個會把動作做一遍的游標**。圖示說的是「有這個功能」；這裡要說的是「你該做什麼」，而一個指標移到按鈕上、按鈕跟著反應，是說出「按那個」最短的方式。

它們是純 CSS，跑在一個共用的六秒週期上。為了讓八個方框動起來而把一個動畫函式庫拉進桌面 bundle，代價由所有從來不會打開它的人一起付；而「在這些時間點改變 opacity 與 transform」正是樣式表直接表達得出來的東西。`prefers-reduced-motion` 會把它全部停下，並讓每個場景停在讀得懂的最後一格。

## 只出現一次，而且從第一格就能離開

`Skip` 放在步驟計數旁邊，而不是在整段序列的最後：一個離不開的導覽比沒有更糟。完成與跳過是同一個持久答案，存在 `first-run` 這個設定區段裡。

**關閉是這個元件自己的答案，不是設定的。** 寫入是一次往返，而在偏好只存在記憶體裡的部署上它根本不會落定；一個要等儲存同意才關的對話框，看起來就是一個壞掉的控制項。

**當那個答案還在路上時，導覽保持隱藏。** `loading` 不等於「沒看過」，而對一個已經關掉它的人、在每次啟動、直到偏好載入為止都再顯示一次，比晚一點顯示更糟。至於根本無法保存偏好的部署，它會顯示——因為全新安裝的人正是它存在的對象，而且永遠可以跳過。

## Model Experience

None，因為這個套件不註冊任何會抵達模型請求的工具、提示、schema 或 context。它的 node 半邊只是為了擁有那個持久區段；其餘全部畫在瀏覽器裡。

#### KV Cache effect

None。這裡沒有任何東西貢獻提示片段、工具定義或 context 條目，所以沒有任何重用邊界會因為它而移動。

## 已知限制與未完成項目

- **沒有回頭路。** 一旦關掉，產品裡沒有任何「再給我看一次」的入口；想要的人得手動去清那個設定。
- **它指不到真的介面。** 那些場景是模擬，所以輸入框或資料夾選擇器一改，它們描述的就會是一個已經不長那樣的東西，而且那件事發生時不會有任何測試變紅。
- **所有人共用同一套導覽。** 一個已經連好遠端機器才來的人，仍然會遇到那段解釋「機器這件事存在」的步驟。
- **場景裡的文字有在地化，版面沒有。** 詞彙長得多的語言，可能會撐破照著出貨那四種語言尺寸做的模擬。
