# @unieai/uad-client-ui-settings-connectors

[English](README.md) | 中文

「連接」設定頁：這個應用程式被允許進入的外部服務、每一條連接涵蓋什麼，以及授予或收回它的那兩顆按鈕。它是[連接器接縫](../../connector/connector/README.zh.md)的介面 —— 這個套件不持有任何 token、不儲存任何授權，也不決定任何協定。

這個 section 以 order 7 註冊進設定殼的 `settings.section` 插槽，位在「通知」之後、「模型」之前。

## 一列就是完整的互動

每個連接器要回答的都是同樣兩個問題 —— 連上了沒有、連的是誰 —— 所以這一頁是一份列表，而不是一格格卡片後面各自藏著詳細頁。一列裡有標誌、服務名稱、一句狀態，以及唯一那個會對它做事的控制項。要找 Google 的人靠圖案就找到了，不必讀完四個標籤 —— 標誌那一欄存在的理由就只有這個。

那句狀態是這樣挑的：頁面上不會出現「技術上正確但實際上沒用」的話。

- **尚未連接**，或者在服務有說出核准帳號時顯示 **已連接 · someone@example.com**。
- 對於供應商沒有發 refresh token 的連接，顯示 **有效期至 2026年9月30日，之後需要重新授權**。那條連接是真的會結束的，而一列只寫「已連接」，等於對下週才回來看的人說謊。只寫到日期、不寫時刻：沒有人會照著 14:37 安排事情。
- **需要先在該服務註冊一個應用程式**，此時「連接」按鈕不可按，旁邊有一段可以展開的說明。理由見下。

## 授權發生在這一頁看不到的地方

按下連接會在使用者自己的瀏覽器裡開啟該服務的登入頁，而開啟它的是 host —— 這個流程監聽的是一個只有跑著 Rabi 的那台電腦才到得了的 loopback redirect，所以由頁面自己去開視窗，等於把錯誤的那個瀏覽器指過去。授權進行中，section 會顯示一則寫著服務名稱的等待訊息和一顆「取消」，因為接下來要做的事在另一個視窗裡，把這件事講出來就是它的全部工作。

由此有兩條規則：

- **一次只能有一個授權。** 兩個開著的視窗會爭同一個 loopback listener，而失敗的那一個給出的理由沒有人能處理。有一個授權開著時，其他每一顆「連接」都會被壓住。
- **取消是中止那次嘗試，而清掉等待訊息的是那次嘗試本身。** 在按下的當下就放掉位置，會讓第二個授權在第一個還在收尾時就開始。

沒有桌面可以開瀏覽器的 host 會在任何人開始等待之前就拒絕：否則流程只會坐在一個永遠不會到達的 redirect 上。

## 為什麼有些連接器在這裡連不了

有發布註冊端點（RFC 7591）的服務會在連接時直接發給這個應用程式一個 client id，所以全新安裝、什麼都沒設定也能用。沒有的服務 —— Google 和 Microsoft 都是 —— 必須先在該廠商註冊一個應用程式，而在同意畫面上代表它的那個編號屬於營運這份建置的人。那不是這裡能一起出貨的東西。

這樣的連接器仍然會被列出來。把它藏起來看起來就像這個連接器不存在，人就會去找它。取而代之的是：那一列說出缺的是什麼，按鈕明白地不可按，註冊說明摺在一個 summary 後面，不需要的人永遠不會讀到。編號要填在 composition 的 `connectors.clientIds`。

## 那些標誌

Google 和 Microsoft 依照兩家廠商自己發布的樣子繪製 —— 平面形狀、官方顏色 —— 因為這兩家要求它們的標誌出現在連接帳號的那個控制項上，也因為人認得標誌比認得字快。

其他連接器一律是一塊帶自己顏色的字母方塊。憑記憶把一個標誌畫得差不多，比不畫更糟：它是看得出來畫錯的，而且那是對商標的誤用。方塊是一個決定，不是一次失敗；而且當某個外掛註冊了這個 fork 從沒聽過的連接器時，它仍然是對的。

## Known Limitations and Deferred Work

- **中斷連接是本機的。** 它刪掉的是這台電腦持有的授權。在使用者自己去該服務撤銷之前，那份核准在服務端仍然有效，而文案就是這樣寫的，不會宣稱一個這個程式做不到的撤權。
- **列表是開頁時讀取，不是持續監看。** 授權只會在有人按了這裡的按鈕、或到服務端撤銷時改變，而這兩件事 host 都不會推播；另一個視窗連上的東西，要重新開這一頁才會反映出來。
- **這裡不說明一條連接被用來做什麼。** 這一頁顯示哪些服務連上了，不顯示哪些工具會用到它們 —— 那屬於對連接器註冊工具的那一方，而目前還沒有這樣的註冊出貨。
- **等待訊息分不出「被放棄的授權」和「很慢的授權」。** 關掉服務登入分頁的人，那次嘗試會一直開著，直到他按下取消；這個流程對「視窗不見了」沒有任何訊號。
- **scope 有存下來但沒有顯示。** 供應商實際授予了什麼，在 wire 上也在授權裡；但一列如果攤開六條 OAuth scope 網址，對這一頁面向的讀者就是不可讀的。那屬於單一連接器的詳細頁，而現在沒有那個頁面。
